# Skill: viz_scaffolding

## Descrição
Geração de código base (boilerplate) para visualizações de dados complexas.[cite: 3]

## Bibliotecas Suportadas
- **Plotly**: Gráficos interativos e dashboards.[cite: 3]
- **Seaborn**: Visualizações estatísticas estáticas.[cite: 3]
- **Matplotlib**: Customizações de baixo nível.[cite: 3]

## Estrutura do Prompt
A skill interpreta comandos como:
"Gere um scatter plot de Preço vs Área, colorido por Categoria, usando Plotly com tema dark."[cite: 3]

## Output
Retorna um bloco de código Python funcional e pronto para execução na IDE.[cite: 3]
